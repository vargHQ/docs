## Overview

varg offers 6 image upscale models ranging from free-tier to premium. All take an image URL and return a higher-resolution version.

| Model ID | Quality | Price | Provider |
|----------|---------|-------|----------|
| `topaz` | Best | $0.16 an image | fal (Topaz Labs) |
| `seedvr` | Very good | $0.10 an image | fal (ByteDance SeedVR) |
| `recraft-clarity` | Good | $0.08 an image | fal (Recraft) |
| `clarity-upscaler` | Good | $0.08 an image | fal |
| `ccsr` | Basic | no charge in today's catalog | fal (free tier) |
| `aura-sr` | Basic | no charge in today's catalog | fal (free tier) |

Prices from the live catalog on 14 November 2026 (1 credit = $0.01). Today's prices: [topaz](https://varg.ai/models/topaz), [seedvr](https://varg.ai/models/seedvr), [recraft_clarity](https://varg.ai/models/recraft_clarity), [clarity_upscaler](https://varg.ai/models/clarity_upscaler), [ccsr](https://varg.ai/models/ccsr), [aura_sr](https://varg.ai/models/aura_sr).

## Quick start

<CodeGroup>
```typescript SDK
import { createVarg } from "vargai/ai"

const varg = createVarg({ apiKey: process.env.VARG_API_KEY! })

const result = await varg.imageModel("seedvr").generate({
  imageUrl: "https://example.com/low-res-photo.jpg",
})

console.log(result.image.url)
```

```bash cURL
curl -X POST https://api.varg.ai/v2/image \
  -H "Authorization: Bearer $VARG_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedvr",
    "prompt": "",
    "files": [{ "url": "https://example.com/low-res-photo.jpg" }]
  }'
```
</CodeGroup>

## Parameters

<ResponseField name="files" type="array" required>
  Single image to upscale: `[{ url: "image.jpg" }]`.
</ResponseField>

<Note>
Upscale models don't use prompt or aspect_ratio. They take a single input image and return it at higher resolution.
</Note>

## Model comparison

| Model | Best for | Pricing model |
|-------|----------|---------------|
| `topaz` | Professional / maximum quality | $0.16 an image |
| `seedvr` | Good quality at moderate cost | $0.10 an image |
| `recraft-clarity` | Design assets, illustrations | $0.08 an image |
| `clarity-upscaler` | General purpose | $0.08 an image |
| `ccsr` | Free/cheap bulk upscaling | no charge in today's catalog |
| `aura-sr` | Free/cheap bulk upscaling | no charge in today's catalog |

## Tips

- **Topaz** produces the best results but is the most expensive. Use for hero images and final deliverables.
- **SeedVR** gives excellent quality at $0.10 an image, against $0.16 for Topaz.
- **CCSR and Aura-SR** carry no charge in today's catalog (they are free at the provider). Good for batch processing.
- **Combine with Phota Enhance** if you need identity-preserving upscaling for faces.
