## What is varg?

varg is an AI video generation platform. Write declarative JSX code like React components, and varg handles AI generation, caching, and video rendering. One API key, one gateway, all providers.

```tsx
/** @jsxImportSource vargai */
import { Render, Clip, Image, Video } from "vargai/react"
import { createVarg } from "@vargai/gateway"

const varg = createVarg({ apiKey: process.env.VARG_API_KEY! })

const cat = Image({
  model: varg.imageModel("nano-banana-pro"),
  prompt: "cute orange cat character, round body, big eyes, Pixar style",
  aspectRatio: "9:16",
})

export default (
  <Render width={1080} height={1920}>
    <Clip duration={5}>
      <Video
        prompt={{ text: "cat waves hello, bounces happily", images: [cat] }}
        model={varg.videoModel("kling-v3")}
      />
    </Clip>
  </Render>
)
```

Render it:

```bash
bunx vargai render hello.tsx --verbose
```

Or submit via API (no local tools needed):

```bash
curl -X POST https://render.varg.ai/api/render \
  -H "Authorization: Bearer $VARG_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "..."}'
```

## Quick Start

<Steps>
  <Step title="Get your API key">
    Sign up at [app.varg.ai](https://app.varg.ai) and copy your API key, or log in from the CLI:
    ```bash
    bunx vargai login
    ```
  </Step>
  <Step title="Install the skill (for AI agents)">
    ```bash
    npx -y skills add vargHQ/skills --all --copy -y
    ```

    ```bash
    bunx vargai render hello.tsx --verbose
    ```
  </Step>
</Steps>

## Why varg?

<CardGroup cols={2}>
  <Card title="One API Key" icon="key">
    Single `VARG_API_KEY` for images, video, speech, music, and lipsync. No juggling provider keys.
  </Card>
  <Card title="Declarative JSX" icon="code">
    Write videos like React components. Compose scenes, add transitions, layer audio.
  </Card>
  <Card title="AI-Native" icon="wand-magic-sparkles">
    Built-in support for Kling, Flux, ElevenLabs, Wan, and more. All through one gateway.
  </Card>
  <Card title="Automatic Caching" icon="bolt">
    Same props = instant cache hit at $0. Re-render videos without re-generating AI assets.
  </Card>
</CardGroup>

- **Social Media Content**: TikTok, Reels, Shorts at scale
- **Talking Characters**: AI avatars with lipsync and captions
- **Product Videos**: E-commerce showcases, before/after transformations
- **Slideshows**: Image sequences with transitions and music
