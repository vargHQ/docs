## Setup

```tsx
import { createVarg } from "vargai/ai"

const varg = createVarg({ apiKey: process.env.VARG_API_KEY! })
```

All models are accessed through the `varg` client. 1 credit = 1 cent.

### Image editing with nano-banana-pro/edit

Edit an existing image with a text prompt:

```tsx
const original = Image({
  model: varg.imageModel("nano-banana-pro"),
  prompt: "woman in casual clothes",
  aspectRatio: "9:16",
})

const edited = Image({
  model: varg.imageModel("nano-banana-pro/edit"),
  prompt: { text: "same woman wearing elegant red dress", images: [original] },
  aspectRatio: "9:16",
})
```

<Warning>
`nano-banana-pro/edit` requires an input image in the prompt. Plain text prompts will fail.
</Warning>

### Character images with Soul (Higgsfield)

Generate consistent characters across scenes with style presets:

```tsx
const character = Image({
  model: varg.imageModel("soul"),
  prompt: "friendly tech influencer, casual hoodie, ring light",
  aspectRatio: "9:16",
  providerOptions: {
    varg: {
      styleId: "REALISTIC",  // REALISTIC, ANIME, EDITORIAL_90S, Y2K, GRUNGE
    },
  },
})
```

Soul is ideal for creating a character once and reusing it across multiple video scenes.

## Video Models

| Model | Code | Duration | Best For | Credits |
|-------|------|----------|----------|---------|
| Kling V3 | `varg.videoModel("kling-v3")` | 3-15s (integer only) | Best quality | 150 |

| Seedance 2 Fast | `varg.videoModel("seedance-2-fast-preview")` | 5 or 10s only | Fast generation (ByteDance) | 150 |
| Kling V2.6 | `varg.videoModel("kling-v2.6")` | 5 or 10s | Quality | 100 |
| Kling V2.5 | `varg.videoModel("kling-v2.5")` | 5 or 10s only | Previous gen | 100 |
| Wan 2.5 | `varg.videoModel("wan-2.5")` | 3-10s | Characters, motion | 75 |
| Minimax | `varg.videoModel("minimax")` | 5-10s | Alternative | 75 |
| LTX | `varg.videoModel("ltx")` | 3-10s | Fast, experimental | 50 |

<Warning>
**Duration constraints are strict:**
- `kling-v3`: integer seconds only (3, 4, 5, ... 15). No decimals.
- `seedance-2-preview` / `seedance-2-fast-preview`: exactly 5 or 10 seconds. Nothing else.
- `kling-v2.5` / `kling-v2.6`: exactly 5 or 10 seconds. Nothing else.
- `wan-2.5`: 3-10 seconds.
</Warning>

### Video prompt formats

```tsx
// Text-to-video
Video({ model: varg.videoModel("kling-v3"), prompt: "ocean waves", duration: 5 })

// Image-to-video (recommended — better quality)
Video({ model: varg.videoModel("kling-v3"), prompt: { text: "camera push-in", images: [img] }, duration: 5 })

// Video-to-video (lipsync)
Video({ model: varg.videoModel("sync-v2-pro"), prompt: { video: vid, audio: speech } })
```

## Music Model

```tsx
<Music
  prompt="upbeat electronic music, cheerful vibes"
  model={varg.musicModel()}
  volume={0.3}
  duration={15}
/>
```

One model: `music_v1` (25 credits). Always set `duration` explicitly.

**Prompt tips**: Include genre, mood, tempo, and instruments. Examples:
- `"chill lofi hip hop, relaxing study vibes"`
- `"epic orchestral cinematic trailer music"`
- `"upbeat pop, energetic, catchy melody"`

## BYOK (Direct Provider Access)

If you have your own provider keys, you can use them directly:

```tsx
import { fal, elevenlabs, higgsfield, replicate } from "vargai/ai"

fal.imageModel("nano-banana-pro")
fal.videoModel("kling-v3")
elevenlabs.speechModel("eleven_v3")
elevenlabs.musicModel()
higgsfield.imageModel("soul")
replicate.imageModel("background-remover")
```

Requires individual provider keys in `.env`. See [BYOK](/byok) for details.
